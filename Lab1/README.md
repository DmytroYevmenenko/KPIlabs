# Scooter Rental Service (Сервіс оренди міського транспорту)

## Основні можливості:
* Перегляд доступних паркувальних станцій та самокатів.
* Оформлення та завершення поїздок користувачами.
* Автоматичний облік тривалості та вартості поїздки.

## Про домен
Домен прокату електросамокатів обрано через актуальність міської мікромобільності та цікаву бізнес-логіку зміни станів об'єктів. Система дозволяє клієнтам знаходити вільний транспорт на зарядних станціях, здійснювати поїздки містом (коли самокат фізично не прив'язаний до жодної парковки) та автоматично розраховувати вартість оренди залежно від часу користування.
